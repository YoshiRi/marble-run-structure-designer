# ADR 0001: Use a 2.5D Discrete Model

## Status

Accepted.

## Context

The main project goal is automatic design and construction assistance, not realistic marble physics.

Quadrilla construction is largely determined by:

- discrete block placement
- discrete height relationships
- part orientation
- rail-hole locations
- internal routing paths

A continuous 3D rigid-body solver would add substantial implementation complexity without helping the primary search problem.

## Decision

Model the construction as:

- 2D planar placement
- discrete height
- discrete rotation
- port-to-port routing
- simplified structural occupancy/support constraints

Detailed 3D meshes and marble animation will live in the viewer layer and will not be solver dependencies.

## Consequences

### Positive

- smaller search space
- easier validation
- easier serialization
- part behavior can be measured manually
- automatic design becomes a graph/constraint problem
- viewer technology can change independently

### Negative

- collision geometry may need incremental refinement
- unusual real-world assemblies may not fit the discrete model immediately
- realistic marble dynamics are not predicted

These are acceptable trade-offs for the current project goals.
